Setup

  1. Extract this project somewhere permanent, e.g. C:\Tools\FirefoxSpotlightSync.
  2. Open PowerShell in that folder and run: 
    Set-ExecutionPolicy -Scope Process Bypass
.\scripts\install.ps1
  3. Fully close and reopen Firefox.
  4. Load the extension: about:debugging#/runtime/this-firefox → Load Temporary Add-on → extension\manifest.json (or install the built .xpi — see the README for a permanent install).

The installer writes the native-messaging manifest with an absolute path to spotlight_host.cmd, so it works from any folder.

Troubleshooting

Run .\scripts\diagnose.ps1 from PowerShell. It verifies the helper files, the generated manifest and its path, the Firefox registry entry, and performs a live round-trip request to the helper.

All wallpaper handling is local. No network service is used.
